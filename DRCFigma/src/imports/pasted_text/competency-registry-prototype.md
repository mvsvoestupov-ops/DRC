1. Общие требования к прототипу
•	Платформа: Figma (предоставить ссылку для комментирования и демонстрации).
•	Тип прототипа: Кликабельный (с возможностью перехода между экранами, без сложной анимации).
•	Разрешение: Десктопное (ширина 1280–1440 px), без адаптива под мобильные устройства (на сессии показывают на больших экранах).
•	Стиль: Чистый, деловой, информационный. Использовать цвета, ассоциирующиеся с государственными / образовательными платформами (синий, серый, белый), с акцентами на ключевые данные.
•	Язык интерфейса: Русский, с возможностью отображения английских полей для демонстрации международной гармонизации.
•	Наполнение: Прототип должен содержать реальные примеры данных (как минимум 2–3 компетенции), взятые из документа (ОК 1, ПК 5, а также одна новая компетенция, например, для цифровой экономики).
 
2. Целевая аудитория и сценарии (для понимания логики навигации)
На стратегической сессии прототип будут просматривать:
•	Разработчики ОПОП (вузы) – им важно видеть, как выбрать компетенцию из реестра и посмотреть её паспорт.
•	Работодатели / СПК – как инициировать новую компетенцию и связать её с профстандартом.
•	Регуляторы (Росаккредагентство) – как осуществляется экспертиза и управление жизненным циклом.
•	Международные партнёры – как найти эквиваленты в ESCO и ISCED.
Ключевые сценарии, которые должен поддерживать прототип:
1.	Просмотр карточки компетенции – увидеть все поля: ID, название, структуру (A, B, C), уровни, трудовые функции, оценочные средства, международные эквиваленты.
2.	Поиск / фильтрация – найти компетенции по профстандарту, трудовой функции, отрасли, статусу.
3.	Добавление / редактирование (упрощённая форма) – показать, как выглядит форма для подачи заявки на новую компетенцию (только основные поля для демонстрации).
4.	Панель управления (административная) – для эксперта: список заявок, возможность утвердить/отклонить.
5.	Интеграция с ЦОП / ПОА – визуализация того, как компетенция отражается в цифровом профиле студента и как используется в ПОА (можно сделать отдельный экран со схемой, либо всплывающую подсказку).
 
3. Структура экранов прототипа (перечень страниц)
1.	Главная страница реестра (дашборд)
o	Краткая статистика: количество компетенций, действующих, на экспертизе, архивных.
o	Кнопки: «Найти компетенцию», «Предложить новую компетенцию», «Войти» (роли).
o	Блок «Последние добавленные компетенции» (3–4 карточки).
o	Блок «Популярные отрасли».
2.	Страница поиска / просмотра списка компетенций
o	Фильтры: по отрасли, по статусу, по профстандарту, по трудовой функции, по уровню образования.
o	Результаты в виде таблицы: ID, название, статус, версия, разработчик.
o	Возможность кликнуть по строке для перехода к карточке компетенции.
3.	Карточка компетенции (детальный просмотр)
o	Вся информация согласно структуре из документа (раздел 2).
o	Вкладки для компактности: «Основное», «Структура (A/B/C) и уровни», «Трудовые функции и связь с профстандартами, квалификациями», «Оценочные средства и технологии», «Международные эквиваленты».
o	Кнопки: «Редактировать» (только для авторизованных пользователей), «Предложить изменения», «Экспорт в JSON/PDF», «Поделиться».
4.	Форма предложения новой компетенции (мастер добавления)
o	Пошаговый интерфейс или длинная форма с группировкой полей (как в таблице «Лист 1»).
o	Обязательные поля: название, описание, структура (A/B/C), связь с трудовой функцией (выбор из справочника профстандартов).
o	Возможность сохранить черновик, отправить на экспертизу.
o	Отображение текущего статуса заявки.
5.	Страница администратора / эксперта (панель модерации)
o	Список заявок на новые компетенции с фильтрами по статусу.
o	Карточка заявки с возможностью просмотра заполненных данных, комментариев эксперта, кнопок «Утвердить», «Отправить на доработку», «Отклонить».
o	(Опционально) График жизненного цикла компетенции (сроки пересмотра).
6.	Интеграционная схема (отдельный экран или всплывающее окно)
o	Визуализация того, как реестр связан с ЦОП, платформой ПОА, целевыми смарт-контрактами.
o	Можно сделать в виде простой инфографики с кликабельными зонами (например, при нажатии на блок «ПОА» показывается текст, как именно используются компетенции).
7.	Страница профиля пользователя (опционально) – упрощённо, чтобы показать, что разные роли видят разные интерфейсы.
 
4. Детальное описание ключевых экранов (элементы управления и содержание)
4.1. Главная страница
•	Хедер: Логотип «Национальный реестр компетенций», строка поиска (глобальный поиск по названию/ID), иконка пользователя (вход/выход), переключатель языка (RU/EN).
•	Секция 1 (герой): Краткое описание реестра (200 символов) и кнопки «Найти компетенцию», «Предложить компетенцию».
•	Секция 2 (статистика): Карточки с цифрами – «Всего компетенций: 1240», «Действующих: 982», «На экспертизе: 34», «Архивных: 224».
•	Секция 3 (последние добавленные): Горизонтальный скролл карточек (мини-версия карточки: название, ID, статус, отрасль).
•	Секция 4 (популярные отрасли): Облако тегов или плитки: «Юриспруденция», «Финансы», «IT», «Образование», «Здравоохранение».
•	Футер: Ссылки на документацию, API, контакты.
4.2. Результаты поиска
•	Верхняя панель: Активные фильтры (можно снять), кнопка «Очистить фильтры».
•	Слева – панель фильтров:
o	Отрасль (выпадающий список с поиском).
o	Статус (чекбоксы: действует, проект, архив).
o	Уровень образования (бакалавриат, магистратура, СПО, ДПО).
o	Профстандарт (текстовый поиск с автодополнением).
o	Трудовая функция (поиск по коду или названию).
•	Справа – таблица результатов:
o	Колонки: ID, Название (сокращённое), Статус, Версия, Разработчик, Дата последнего обновления.
o	Каждая строка кликабельна – ведёт на карточку компетенции.
o	Пагинация.
4.3. Карточка компетенции (подробный просмотр)
•	Верхняя часть: Название компетенции, ID, версия, статус (цветной бейдж), кнопки «Редактировать» (если права), «Экспорт», «Поделиться».
•	Вкладка 1 – Основное:
o	Полное описание.
o	Уровни освоения (в виде таблицы или карточек).
o	Рекомендуемая трудоёмкость.
o	Отрасль / область деятельности.
•	Вкладка 2 – Структура (A/B/C):
o	Три колонки: Знания (A), Умения (B), Навыки (C).
o	Каждый пункт с возможностью развернуть пример (тултип).
•	Вкладка 3 – Профстандарты и трудовые функции:
o	Список профстандартов с названием, кодом.
o	Под каждым – перечень трудовых функций (код и описание).
o	Возможность перейти к полному тексту профстандарта (внешняя ссылка).
•	Вкладка 4 – Оценочные средства и технологии:
o	Типовые задания (краткое описание, можно скачать шаблон).
o	Рекомендуемые методы обучения.
o	Примеры оценочных материалов.
•	Вкладка 5 – Международные связи:
o	ESCO ID (кликабельная ссылка).
o	ISCED код.
o	Страны признания (список флагов).
•	Секция «Использование в экосистеме» (внизу):
o	Иконки с подписями: «ПОА», «Целевое обучение», «ЦОП». При клике – всплывающая подсказка с пояснением.
4.4. Форма предложения новой компетенции (для разработчика)
•	Прогресс-бар (шаги: 1. Общая информация → 2. Структура A/B/C → 3. Связь с профстандартами → 4. Оценочные средства → 5. Предпросмотр).
•	Шаг 1: Название, описание, отрасль, уровень образования, трудоёмкость.
•	Шаг 2: Добавление компонентов A, B, C (динамические блоки).
•	Шаг 3: Поиск и выбор профстандарта, затем выбор конкретной трудовой функции.
•	Шаг 4: Загрузка файлов с типовыми заданиями / ссылки.
•	Шаг 5: Предпросмотр карточки, кнопка «Отправить на экспертизу».
•	Боковая панель: Правила заполнения, подсказки.
4.5. Панель модератора (эксперта)
•	Список заявок (таблица): ID заявки, название компетенции, дата подачи, текущий статус, эксперт.
•	При клике на заявку открывается:
o	Предпросмотр карточки компетенции (нередактируемый).
o	Блок комментариев эксперта (текстовое поле, история).
o	Кнопки: «Утвердить», «Отправить на доработку», «Отклонить».
o	Поле для указания причины отказа / замечаний.
•	График пересмотров (календарь) для действующих компетенций.
 
5. Примеры данных для наполнения прототипа (должны быть использованы)
Компетенция 1 (из документа РГГУ – ПК-5)
•	ID: RUS-PK-05-v1
•	Название: Способен применять нормативные правовые акты, реализовывать нормы материального и процессуального права в профессиональной деятельности
•	Описание: … (сокращённо)
•	A/B/C: как в документе.
•	Трудовые функции: Профстандарт «Специалист по юридическому сопровождению» (03.008), ТФ «Правовая экспертиза документов».
•	Международные эквиваленты: ESCO «apply legal regulations».
•	Уровни: достаточный, повышенный, превосходный.
Компетенция 2 (ОК-1 из документа)
•	ID: RUS-OK-01-v2
•	Название: Осознаёт социальную значимость своей будущей профессии, обладает достаточным уровнем профессионального правосознания.
•	Описание: …
•	A/B/C: (взять из паспорта в документе).
•	Связь с профстандартом необязательна, но может быть опциональной.
Компетенция 3 (новая – для демонстрации цифровой экономики)
•	ID: RUS-DIG-01-v1
•	Название: Способен применять методы анализа больших данных (Big Data) для решения профессиональных задач в области финансового мониторинга.
•	Описание: …
•	Трудовые функции: Профстандарт «Специалист по финансовому мониторингу» (например, из профстандарта 08.037).
•	Международные эквиваленты: ESCO «analyse big data», ISCED.
