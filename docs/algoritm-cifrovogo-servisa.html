Графическая схема алгоритма работы цифрового сервиса

Национальный реестр компетенций (DRC): от создания паспорта и работы рабочей группы до экспертизы, публикации в реестре и международного сопоставления.

Схемы рисуются автоматически (Mermaid). Нужен интернет при первом открытии. Печать: Ctrl+P. Файл: docs/algoritm-cifrovogo-servisa.html

Схемы 1. Жизненный цикл 2. Доступ 3. Конструктор 4. Рабочая группа 5. Автосохранение 6. «В разработке» 7. Экспертиза 8. Общая карта сервиса
Старт / вход Действие Решение (ветвление) Успех / публикация Блок / конфликт / возврат

1. Жизненный цикл компетенции

Статусы записи: проект → на экспертизе → утверждена (либо возврат в проект).

flowchart TD
  A([Создание или приглашение в группу]) --> B[Статус: проект
черновик паспорта]
  B --> C{Паспорт заполнен
для экспертизы?}
  C -->|Нет| B
  C -->|Да| D[Руководитель отправляет
на экспертизу]
  D --> E[Статус: на экспертизе
модератор назначает экспертов]
  E --> F{Решение экспертизы}
  F -->|Утвердить| G([Статус: утверждена
открытый реестр])
  F -->|Вернуть / отклонить| B

  style F fill:#fef3c7,stroke:#b45309

2. Доступ к функциям сервиса

Гость видит открытый реестр; разработка и служебные разделы — после входа.

flowchart TD
  S([Открытие сайта]) --> T{Действие требует
учётной записи?}
  T -->|Нет| U[Главная, поиск, карточки
утверждённых и на экспертизе]
  T -->|Да| V{Пользователь
авторизован?}
  V -->|Нет| W[/Окно входа или регистрация/]
  W --> X[Подтверждение email при регистрации]
  X --> V
  V -->|Да| Y[Предложить компетенцию,
проекты, рабочая группа,
экспертиза по роли]

4. Рабочая группа

Создатель — руководитель; участники совместно правят черновик; на экспертизу отправляет только руководитель.

flowchart TD
  A([Руководитель открывает
«Рабочая группа»]) --> B[Поиск по ФИО / выбор
из справочника пользователей]
  B --> C[Пригласить выбранного]
  C --> D[Участник видит приглашение
в «Мои проекты»]
  D --> E{Принять?}
  E -->|Нет| F([Отклонено])
  E -->|Да| G[Совместное редактирование
presence, чат шагов]
  G --> H{Кто отправляет
на экспертизу?}
  H -->|Руководитель| I([Отправка на экспертизу])
  H -->|Участник| J[/Запрещено:
только руководитель/]
  style A fill:#dbeafe,stroke:#1e40af
  style E fill:#fef3c7,stroke:#b45309
  style H fill:#fef3c7,stroke:#b45309
  style G fill:#eef2ff,stroke:#4f46e5
  style I fill:#d1fae5,stroke:#047857

5. Автосохранение при групповой работе

Пустая вкладка не затирает чужие поля; при конфликте версий сохранение отклоняется.

flowchart TD
  A([Таймер автосохранения
примерно каждые 5 минут]) --> B{Есть локальные изменения
после загрузки?}
  B -->|Нет| C([Автосейв пропущен
dirty-gate])
  B -->|Да| D[PUT на сервер
с expected_updated_at]
  D --> E{Версия на сервере
совпадает со снимком?}
  E -->|Да| F([Сохранено
updated_at обновлён])
  E -->|Нет| G[/409 Conflict:
чужие правки не затираются
обновить страницу/]

6. Карточка дашборда «В разработке»

Счётчик всех черновиков («проект»). Состав групп виден всем авторизованным; правка — только участникам.

flowchart TD
  A([Клик: «В разработке»]) --> B{Авторизован?}
  B -->|Нет| C[/Окно авторизации/]
  C --> B
  B -->|Да| D[Список всех компетенций
со статусом «проект»]
  D --> E[Показ состава
рабочей группы]
  E --> F{Пользователь — участник
разработки этой записи?}
  F -->|Да| G([Кнопки:
Просмотр + Редактирование])
  F -->|Нет| H([Кнопка:
только Просмотр])
  style A fill:#dbeafe,stroke:#1e40af
  style B fill:#fef3c7,stroke:#b45309
  style F fill:#fef3c7,stroke:#b45309
  style C fill:#ffe4e6,stroke:#be123c
  style G fill:#d1fae5,stroke:#047857
  style H fill:#eef2ff,stroke:#4f46e5
  style D fill:#fff7ed,stroke:#c2410c

7. Экспертиза и публикация

Модератор назначает экспертов; эксперт выносит решение по чек-листу.

flowchart TD
  A([Заявка: на экспертизе]) --> B[Модератор назначает
не менее 3 экспертов]
  B --> C[Эксперт заполняет чек-лист
и комментарии]
  C --> D{Итоговое решение}
  D -->|Утвердить| E([Утверждена:
открытый поиск и счётчики])
  D -->|Вернуть| F[Снова статус «проект»]
  F --> G[Доработка рабочей группой]
  G --> A
  style A fill:#fff7ed,stroke:#c2410c
  style D fill:#fef3c7,stroke:#b45309
  style E fill:#d1fae5,stroke:#047857

8. Общая карта цифрового сервиса

Сводка основных контуров платформы на одном листе.

flowchart TB
  subgraph Open["Открытый контур"]
    H[Главная и поиск] --> K[Карточка компетенции]
    K --> DOC[Выгрузка DOCX]
  end

  subgraph Dev["Контур разработки"]
    N[Предложить компетенцию] --> WZ[Конструктор 1–10]
    WZ --> WG[Рабочая группа]
    WG --> AUT[Автосохранение
и защита версий]
    DEV[Реестр «В разработке»]
  end

  subgraph Exp["Контур экспертизы"]
    REV[На экспертизе] --> MOD[Модератор]
    MOD --> EXP[Эксперты]
    EXP --> PUB[Утверждена / возврат]
  end

  subgraph Intl["Международный контур"]
    GARM[ГАРМ-ESCO / шаг 9]
    BRICS[Harmoni-BRICS]
    BRIDGE[Каталог мостов и шаг 9.2]
  end

  H --> N
  WZ --> REV
  PUB --> H
  WZ --> GARM
  WZ --> BRICS
  BRIDGE --> WZ
